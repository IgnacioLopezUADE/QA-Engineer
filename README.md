# QA Engineer

## Quality Assurance

### Que es el control de calidad?
+ Que tan bien cumple con las necesidades y expectativas del cliente
+ Funcionalidad: El producto hace lo que se espera que se haga
+ Disueño: Intuitivo
+ Fiabilidad: Funciona de manera correcta en distintos contextos

### Assurance
Garantia:
* Cumple con las expectativas
* Funciona correctamente
* No presenta problemas

### Software Testing
Garantizar la calidad de un producto antes de que llegue a los usuarios finales

### Objetivo principal
Prevenir los errores en el desarrollo

### Caracteristicas claves del QA
+ Es un proceso preventivo
+ Enfocado en procesos
+ Asegura confianza en el producto

### Diferencias entre QA y Testing
QA:
* Preventivo y asegura la calidad
* Procesos estandares
* Mejora el ciclo de desarrollo

Testing:
* Actividad para encontrar defectos
* Procucto final
* Verifica si el producto cumple con los requisitos
